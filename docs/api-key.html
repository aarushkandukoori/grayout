Use your own API key

Grayout is open source under the MIT license. You can run it on your own OpenAI or Anthropic account, pay your provider directly, and keep the Grayout service out of the path entirely.

Today’s release works this way out of the box

Grayout 1.0.1 asks for a key during setup. Get one below, paste it, and you are done.

Looking for a Grayout Pro license key (it starts with gry_) instead? That lives on the account page.

Get a key in two minutes

OpenAI

  1. Sign in at platform.openai.com and open API keys.
  2. Click Create new secret key and copy it. It starts with sk-.
  3. Add prepaid credit under Billing. New accounts need at least $5, which lasts a long time at a fraction of a cent per check.

Anthropic

  1. Sign in at platform.claude.com and open API keys.
  2. Click Create key and copy it. It starts with sk-ant-.
  3. Add at least $5 of prepaid credit under Billing. It can take a minute to show up.

Paste it into Grayout

In 1.x: the welcome window asks for it on the Your API key screen. Paste it, click Test key, then Save and continue. Grayout works out the provider from the key. To change it later, open Settings from the menu bar. macOS asks once whether Grayout may use its own Keychain item; click Always Allow.

In 2.0 and later, new installs use the Grayout service by default (100 free checks, then Grayout Pro). A Mac that already has a key saved keeps using it. To choose your own key explicitly, set provider in ~/Library/Application Support/Grayout/config.json:

{
  "provider": "openai",
  "model": "gpt-5-mini",
  "changeGating": true
}

Use "anthropic" with "claude-haiku-4-5" for an Anthropic key, or "grayout" to use the Grayout service. Then run it from source with the key in the environment:

git clone https://github.com/aarushkandukoori/grayout
cd grayout
npm ci
npm run helper
OPENAI_API_KEY=sk-... npm start

Keys are stored encrypted with your Keychain, never logged, and never written to a plain file. Revoke a key any time in your provider’s console.

What it costs

Your provider bills you for every check. List prices as of September 2026, one display:

Provider and modelPer checkA working day at the 45-second default
OpenAI, gpt-5-miniAbout $0.0007About $0.25
Anthropic, claude-haiku-4-5About $0.0025About $0.90

The webcam adds about 15%. Each extra display adds about one more screenshot’s worth to the cost of a check. Grayout stops for the day at 1,200 checks, and a spending limit in your provider’s console is the simplest hard cap.

If a key is refused

  • The provider rejected this key: a character is missing or the key was revoked. Paste it again or make a new one.
  • This account has no credit: both providers need prepaid credit before the first call. It can take a minute to appear after you pay.
  • This account cannot use the model: try another key, or set model in config.json to one the account can use.
  • The provider could not be reached: check your connection, a VPN, or a firewall blocking api.openai.com or api.anthropic.com.

Run the service yourself

The Grayout service is in the repository too, under server/: a Cloudflare Worker. Every endpoint is written down in API-CONTRACT.md. Point the app at your own deployment with apiBase in config.json. Only https addresses, or http on localhost, are accepted, so a typo can’t quietly send screenshots somewhere you didn’t choose.

Every setting and its range is in the README. This path gets community support on GitHub.
