Self-hosting

Grayout is a subscription: the app sends a screenshot to the Grayout service, and the service asks the model with its own key. You never get one, never paste one, and never see a per-check bill. The plans are here.

This page is the other path. The whole app is in the repository under an MIT license, so you can point it at your own Anthropic or OpenAI account instead. That disables the Grayout service completely: no license, no subscription, and no request to api.grayout.app. It is a build-from-source path rather than something the packaged app is set up for, it gets no support beyond the repository, and it is not going away.

Turning it on

Set provider in ~/Library/Application Support/Grayout/config.json to the provider whose key you hold.

{
  "provider": "openai",          // or "anthropic"; "grayout" forces the subscription
  "model": "gpt-5-mini",         // or "claude-haiku-4-5" with an Anthropic key
  "changeGating": true,          // keeps your own bill down too
  "forceCheckSec": 180
}

The default, "auto", already does this: a Mac with a model key saved runs on that key's provider, and a Mac without one uses the subscription. Setting provider explicitly is how you stop that from depending on whatever happens to be in your Keychain.

Then run it from source with the key in the environment:

git clone https://github.com/aarushkandukoori/grayout && cd grayout && npm ci && npm run helper
OPENAI_API_KEY=sk-... npm start       # or ANTHROPIC_API_KEY=sk-ant-...

Keys live in the macOS Keychain when the app saves one. They are never logged and never written to a plain file. Revoke one at any time at console.anthropic.com or platform.openai.com.

What it costs on your own key

Your provider bills you directly for every check. List prices as of 2026-09-22, for one display with change-gating on:

Provider and modelPer checkA month of watched work (about 4,000 checks)
OpenAI, gpt-5-miniabout $0.0007about $3
Anthropic, claude-haiku-4-5about $0.0025about $10

The webcam adds about 15%. Each additional display roughly doubles the per-check cost. dailyCheckCap (1,200 checks) is the hard stop inside the app. A workspace spend limit at console.anthropic.com, or a project budget at platform.openai.com, is the simplest real cap.

Running the service yourself

There is a third option in between. server/ in the repository is the Cloudflare Worker that answers api.grayout.app, and apiBase in config.json points the app at your own deployment of it. Every endpoint and payload is written down in docs/API-CONTRACT.md. An apiBase that is not https, or not localhost over http, is refused and logged rather than used, so a typo cannot quietly send your screenshots somewhere you did not choose.

If a key is refused

  • The provider rejected this key — a character is missing, or the key was revoked. Paste it again or make a new one.
  • This account has no credit — both providers need a prepaid balance before the first call. It can take a minute to appear after payment.
  • This account cannot use the model — the key belongs to an account without access to the default model. Try another key, or set model in config.json to one the account can use.
  • The provider could not be reached — check your connection, a VPN, or a firewall that blocks api.anthropic.com or api.openai.com.

The full self-hosting notes, including every config key and its range, are in the repository README.
