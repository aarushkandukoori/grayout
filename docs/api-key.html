Get an API key in two minutes

Grayout runs on your own Anthropic or OpenAI account, so you pay them directly and nothing goes through us. You need one key, from either; the app tells them apart and keeps it in your macOS Keychain.

Anthropic

  1. Sign up. Go to console.anthropic.com and create an account. This is the developer console, separate from a Claude.ai subscription; a Claude Pro or Max plan does not include API credit.

  2. Add $5. Open Billing and add $5 of prepaid credit, the minimum. That is about a week of Grayout checks at the default setting. Credit is only spent when checks run.

  3. Set a ceiling (optional but recommended). Settings > Workspaces > create a workspace named Grayout and give it a monthly spend limit, for example $30. Keys made inside that workspace cannot spend past it, so the app can never exceed what you set, whatever happens.

  4. Create the key. API keys > Create key, inside that workspace. Copy it. It starts with sk-ant- and is shown once; if you lose it, make a new one.

  5. Paste it into Grayout. Step 3 of the welcome window: paste the key and click Test key. Grayout runs one real check on a synthetic screenshot and tells you what it cost, about a quarter of a cent. Click Save and continue, then Always Allow on the Keychain prompt.

OpenAI

  1. Sign up. Go to platform.openai.com and create an account. This is the developer platform, separate from a ChatGPT subscription; ChatGPT Plus or Pro does not include API credit.

  2. Add $5. Settings > Billing > add $5 of prepaid credit, the minimum. That is about a month of Grayout checks at the default setting. Credit is only spent when checks run.

  3. Set a ceiling (optional). Projects > create a project named Grayout and give it a monthly budget. Keys made inside that project cannot spend past it.

  4. Create the key. API keys > Create new secret key, inside that project. Copy it. It starts with sk-proj- and is shown once; if you lose it, make a new one.

  5. Paste it into Grayout. Step 3 of the welcome window: paste the key and click Test key. Grayout runs one real check on a synthetic screenshot and tells you what it cost, about a fifteenth of a cent. Click Save and continue, then Always Allow on the Keychain prompt.

Grayout never sees your account; the key is stored in your macOS Keychain. It is never logged and never written to a plain file. You can change it later under Settings, and revoke it at any time at console.anthropic.com or platform.openai.com.

What the checks cost

The app is free. Your provider bills each check: about a quarter of a cent on Anthropic’s Claude Haiku 4.5 ($0.0025), about a fifteenth of a cent on OpenAI’s gpt-5-mini ($0.0007). What that adds up to depends on how often Grayout looks, which you choose in the welcome window and can change in Settings.

The webcam adds about 15%. Each additional display roughly doubles the per-check cost. The theoretical ceiling, eight hours nonstop at 30 seconds, is about $2.60 a day with Anthropic and about $0.70 with OpenAI, and a built-in daily cap of 1,200 checks pauses Grayout until tomorrow if it is ever reached.

The dashboard shows what you have spent today, how many checks that was, and the pace it projects for the month, all computed on your Mac from the token counts your provider returns with every verdict. Your actual bill is whatever your provider charges; check it under Usage at console.anthropic.com or platform.openai.com.

If Test key fails

  • Anthropic (or OpenAI) rejected this key — a character is missing or the key was revoked. Paste it again or make a new one.
  • This account has no credit — go back to step 2. Credit can take a minute to appear after payment.
  • This account can’t use the model — the key belongs to an account without access to the default model. Try a different key, or set model in config.json to one your account can use.
  • Couldn’t reach Anthropic (or OpenAI) — check your connection, a VPN, or a firewall that blocks api.anthropic.com or api.openai.com.

You can skip the key during setup and add it later; Grayout stays paused and says so in its menu until it has one.
