WHAT IT DOES
Grayout is a menu bar app. On a timer it takes a screenshot of each display, asks the Grayout service whether the person is clearly off task (social feed, entertainment video, games), and after two such checks in a row turns the screen grayscale with a red border until they return to work. It never blocks, closes or locks anything. No sign-in or account is needed.

HOW TO TEST WITHOUT PAYING (about 3 minutes)
1. Launch Grayout. The first screen names OpenAI and lists what is sent at each check. Click Allow and continue.
2. Click Open System Settings, turn on Grayout under Screen & System Audio Recording, then click Relaunch Grayout.
3. On "Start watching", click Try 100 checks free. No card or account.
4. On "Set it up", choose Strict (every 30 seconds) so it reacts faster.
5. On "See what it does", click Preview the gray to see the effect for a few seconds. Then click Start watching.
6. In Safari, open a video site and play a video, or open a social media feed. After two checks (usually 1 to 2 minutes) the screen turns gray with a red border.
7. Switch to a document: color returns at the next check. Or click the menu bar icon, then I'm working (color returns now; it then waits 10 minutes). Restore color now, Pause and Quit also restore color at once.
Video-call apps (FaceTime, Zoom) never trigger it and password managers are never captured, so test with Safari in front. Checks pause after 10 minutes with no keyboard or mouse input.
If the free checks run out (they are also capped per network, which a shared review network can hit), open Settings from the menu bar icon, go to Your plan, paste this complimentary review key and click Activate: <REVIEWER_LICENSE_KEY>
It stays active through review.

WHY SCREEN RECORDING
The core feature: one screenshot of each display per check, resized to 1366 px wide, sent over HTTPS, and deleted from the Mac right after the check. The camera is optional, off by default, and asked for only if the user turns on the webcam option.

THIRD-PARTY AI (5.1.2(i))
Screenshots, the frontmost app's name, and the optional webcam frame, work description and task titles go to the Grayout service (a Cloudflare Worker we run), which sends them to OpenAI's API under our account and returns a verdict. The service stores no images. OpenAI does not train on API data and may keep inputs up to 30 days for abuse monitoring. The app names OpenAI and asks for explicit permission on its first screen, before any capture; Not now captures nothing. Settings > Send screenshots for checks withdraws it and stops all checks.

HOW THE GRAY WORKS (2.5.1, public APIs only)
A bundled helper, sandboxed like the app, puts one transparent, click-through window above other windows on each display. Its layer uses a Core Animation blend mode (CALayer compositingFilter) to desaturate what is beneath it, so the screen looks gray while every app keeps working. The red border is a separate window above it. No display or accessibility settings are changed. The helper exits when Grayout quits or crashes (its input pipe closes or its parent is gone), so the screen cannot stay gray.
